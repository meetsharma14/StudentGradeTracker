Student Grade Tracker (Java)

A simple Java console application that records student names and grades, then generates a summary report including the average grade, highest grade, and lowest grade.

This project demonstrates basic Object-Oriented Programming (OOP) concepts and the use of Java collections for managing data.

Features
Add multiple students and their grades
Calculate average grade
Identify highest and lowest grades
Display all student records
Simple console-based interface
Tech Stack
Java
ArrayList (Java Collections Framework)
Scanner for user input
Example Output
=== Student Grade Tracker ===
Enter the number of students: 3

Enter name of student 1: Rahul
Enter grade for Rahul: 85

Enter name of student 2: Priya
Enter grade for Priya: 92

Enter name of student 3: Aman
Enter grade for Aman: 76

=== Summary Report ===
Average Grade: 84.33
Highest Grade: 92.00 (by Priya)
Lowest Grade: 76.00 (by Aman)

--- Student Details ---
Rahul - Grade: 85.0
Priya - Grade: 92.0
Aman - Grade: 76.0
Concepts Used
Object-Oriented Programming (Classes & Objects)
Java Collections (ArrayList)
Loops and conditional statements
User input handling with Scanner
How to Run

Compile:

javac StudentGradeTracker.java

Run:

java StudentGradeTracker
